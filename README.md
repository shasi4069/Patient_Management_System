# Patient Management System

Patient Management System is a console-based Java application built as a college project using **Java (Core + JDBC)**, **MySQL**, and **Maven**.  
This system manages patient information and healthcare data through a menu-driven CLI, demonstrating how Java applications interact with relational databases using JDBC.

---

## 📌 Project Summary

This application enables basic management of patient records and related operations.  
It is designed to help students learn real-world backend concepts like:

- Database connectivity  
- CRUD operations  
- Modular application design  
- Interaction between Java & MySQL using JDBC  

---

## 🚀 Key Features

- Add new patient records  
- View all patients  
- Update existing patient details  
- Delete patients  
- Persistent storage using MySQL  
- Menu-based Command Line Interface (CLI)

---

## 🛠️ Tech Stack

- **Programming Language:** Java  
- **Database Connectivity:** JDBC  
- **Database:** MySQL  
- **Build Tool:** Maven  
- **Interface:** Command Line Interface (CLI)

---

## 📂 Project Structure

The project follows a modular architecture with the following packages:

- **controller** – Handles user interaction and navigation  
- **dao** – Data Access Objects for database operations  
- **model** – Core data models (e.g., `Patient`)  
- **service** – Business logic for operations  
- **util** – Utility classes such as database connection helper  

---

## 📦 Prerequisites

Ensure you have the following installed:

- Java **JDK 8+**  
- **Apache Maven**  
- **MySQL Server**  
- MySQL JDBC Connector (added via Maven dependency)
